
# API DISNEY

Projeto desenvolvido para pesquisar de forma interativa vários personagens do Universo DISNEY


-Busque personagens por nome e também por ID

-Encontre filmes e séries de cada personagem

# Foram utilizados neste projeto: 

- HTML
- CSS
- JavaScript 
- [Disney API](https://disneyapi.dev/)
